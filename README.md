# Tools in This Repo

This repository now contains two standalone browser tools:

- `index.html`: the original `mard` bead pattern tool
- `doc-framework-editor/index.html`: the document framework editor / mind map / Excel export tool

## Document Framework Editor

Path in the repo:

```text
doc-framework-editor/index.html
```

What it does:

- edit Markdown-based document outlines
- render the outline as a mind map or fishbone diagram
- fold and expand body content under headings
- export Excel sheets for document planning

## Open Locally

You can open the editor directly in a browser:

```text
doc-framework-editor/index.html
```

or with a local file URL after cloning the repo.

## GitHub Pages

If this repo is published with GitHub Pages from the repository root, the editor page will be available at:

```text
/doc-framework-editor/
```

For example, with the current remote naming, the expected URL would be:

```text
https://wangyinyao123-alt.github.io/mard-tool/doc-framework-editor/
```

## Notes

- The editor is a single-file static app.
- It depends on CDN-hosted browser libraries referenced inside the HTML file.
- No build step is required.
